# Frontend Mini Projects

A collection of small and practical projects built using **HTML, CSS, and JavaScript** to practice frontend development and strengthen programming fundamentals.

## 🚀 About

This repository contains a variety of beginner-friendly projects focused on:

* HTML structure
* CSS styling and responsive design
* JavaScript fundamentals
* DOM manipulation
* Event handling
* Form validation
* User interactions
* Basic browser functionality

Each project is kept simple and focused on learning core concepts.

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**
* **DOM Manipulation**
* **Responsive Web Design**

## ▶️ How to Use

1. Clone the repository.
2. Open any project folder.
3. Run the `index.html` file in a browser.

You can also use **VS Code + Live Server** for development.
